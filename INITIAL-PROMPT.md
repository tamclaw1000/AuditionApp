# INITIAL-PROMPT.md

## Original project prompt

Create a new project called AuditionApp, initialize git and push to github as AuditionApp.

Create the following requirements:

### APPLICATION-REQUIREMENTS.md
Generate a music submission website for prospective musicians to submit one or more auditions. Create a front end for organizations to register and publish submission requirements for the musicians to browse and register themselves to the organizations.

### TECHNICAL-REQUIREMENTS.md
1. Web application: Apex free tear on Oracle Cloud, newest version with the development language that allows agents to develop the app.
2. iPhone/Android development framework I would do deeper research with AI to choose the best match for the project.
3. Development task management: Jira - free 10 users instance.
4. Cloud storage: Enterprise grade but inexpensive with free tier available for initial playground/testing.
5. Testing framework, probably AI powered.
6. Communication chat: Telegram maybe.
7. Architecture diagrams: Miro? 3 free diagrams, I don’t think we need more for the project.

### ARCHITECTURE.md
Include:
1. A data model for the system.
2. The following workflows:
   - Organization workflows
     - New organization registration
     - Existing organization login
     - Manage audition events
       - Add new
       - Review applicants
   - Musician workflows
     - New user registration
     - Existing users login
     - Apply for audition
     - Upload video

Store the documents into `docs/`.
